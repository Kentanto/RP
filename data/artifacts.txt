# Athas artifact archetypes.
#
# Artifacts are self-generating: when the game rewards an artifact it
# picks one of these archetypes (by weight), rolls a main stat and sub
# stats within the given ranges, generates a name, and draws the icon
# from icon + color. No image files needed.
#
# Fields:
#   rarity:     common | rare | epic | legendary
#   weight:     how often this archetype is picked (higher = more common)
#   icon:       shape name or image file inside icons/
#   color:      r,g,b for the drawn icon
#   max_level:  level cap of generated instances
#   main_stats: STAT=low-high, ...   one is picked as the main stat
#   sub_stats:  STAT=low-high, ...   rolled for sub stats
#               percent stats must end with % (rolled as fractions)
#   lore:       flavor text shown in the detail screen
