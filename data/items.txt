# Athas item definitions.
#
# Every item is one [key] block. Fields:
#   type:      weapon | armor | consumable | material | quest
#   category:  normal | special   (special items get their own tab + styling)
#   rarity:    common | uncommon | rare | epic | legendary
#   icon:      shape name (sword, axe, bow, shield, helm, chest, potion, gem,
#              ring, scroll, star, orb, crystal, fang, feather, book, crown,
#              key) or an image filename inside icons/
#   color:     r,g,b used to draw the icon
#   stats:     stat=value pairs shown in tooltips (atk, def, hp, mana, crit_rate, spd...)
#   price:     shop price in points      sell_price: what selling gives
#   shop:      yes/no   whether it appears in the shop
#   stock:     -1 = unlimited, 0 = sold out, N = limited stock
#   stackable: yes/no   max_stack: cap per stack
