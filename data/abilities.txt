#   base:      stat=value pairs of the skill root (damage, mana_cost, ...)

#   level_req: skill level required to unlock
#   cost:      unlock cost in points
#   boost:     stat=value pairs; damage boosts stack additively,
#              new stats appear on the skill
#   requires:  keys of upgrades that must be owned first (empty = root row)
#   glyph:     mastery, flame, burst, star, cluster, meteor, snow, arrow,
#              shield, chain, wave
